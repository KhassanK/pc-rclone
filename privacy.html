Privacy Policy

Last updated: November 16, 2026

Overview

Personal Rclone Sync is a private application used to synchronize files between personal devices and Google Drive using rclone.

Data Access and Usage

The application accesses Google Drive files through Google OAuth 2.0 solely to perform file synchronization requested by the user.

Data Storage and Sharing

Files are stored on the user's devices and in the user's Google Drive account. The application does not operate an independent server or sell personal data.

Authentication

Authentication is handled through Google OAuth 2.0. Authentication tokens are stored locally by rclone.

Data Deletion

Users can delete synchronized files and revoke application access through their Google Account security settings.
